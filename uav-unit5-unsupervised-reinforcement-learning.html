WP 01
Departure · learning without labels

Unsupervised Learning Overview

Unsupervised learning finds structure in data that has no labels — no bounding boxes, no answers. Given a stream of drone imagery or telemetry, it asks: what groups exist, what is normal, what is unusual, how does the data lay itself out? For a UAV this turns raw, unlabelled flight data into usable structure without the cost of human annotation.

Three jobs. Clustering groups similar observations (parking-lot vs field, vehicle vs vegetation) with no class names. Anomaly detection learns "normal" and flags departures from it (a stalled engine reading, an intruder). Dimensionality / topology (PCA, self-organizing maps) lays high-dimensional data onto a map you can read.

Unsupervised object discovery

Without labels you can still discover objects: cluster pixels or region features into coherent segments, or use self-supervised pretext tasks to learn representations, then group them. Useful when a new UAV mission has imagery but no annotated dataset yet.

Why UAVs need it

Aerial data is abundant and labels are scarce. Unsupervised methods triage the flood — grouping scenes, surfacing rare events, compressing telemetry — so humans (or a supervised model) only look where it matters.

  • Clustering — K-means, DBSCAN, Gaussian mixtures: partition data into groups by similarity.
  • Anomaly detection — statistical, distance, density or reconstruction error: flag the abnormal.
  • SOM / manifold — project and organise high-dimensional data onto a low-dimensional map.
  • No ground truth — quality is judged by internal measures (compactness, separation), not accuracy.
Exam line — Supervised learning maps inputs to known labels; unsupervised learning finds structure in unlabelled data. Detection here means grouping/segmenting without class names, not the labelled bounding boxes of Units III–IV.
WP 02
Climb · grouping

Clustering

Clustering partitions observations into groups whose members are more similar to each other than to those in other groups — with no labels. K-means is the workhorse: pick K, place K centroids, assign each point to its nearest centroid, move each centroid to its members' mean, and repeat until nothing changes.

K-means objective. Minimise the within-cluster sum of squares — total squared distance from each point to its centroid. Each assign–update pass can only lower it, so it converges (to a local optimum that depends on the initial centroids).
Choosing K

K is not learned. Sweep it and watch the within-cluster spread fall; the "elbow" where extra clusters stop helping is a common pick. Domain knowledge (how many object types you expect) usually decides.

Beyond K-means

DBSCAN finds arbitrary shapes and marks outliers by density, no K needed. Gaussian mixtures give soft, probabilistic memberships. K-means assumes round, similar-sized blobs.

UAV use — cluster detections by position to find parking rows, group pixels for unsupervised segmentation, or bin flight patterns. Watch the centroids settle below.

WP 03
En route · the abnormal

Anomaly Detection

Anomaly detection learns what normal looks like and flags what doesn't fit. Most UAV data is routine; the rare, valuable events — a malfunction, an intruder, a defect — are exactly the ones with no training examples. So instead of learning the anomaly, you model normality and measure the distance from it.

How it works

Fit a model of normal data (mean/covariance, a density, or an autoencoder). Score each new point by how far or how unlikely it is; threshold the score. High score → anomaly. The threshold trades missed anomalies against false alarms.

Families

Statistical (z-score, Mahalanobis distance), distance/density (k-NN, LOF, isolation forest), and reconstruction (autoencoder error): normal data reconstructs well, anomalies don't.

  • Class imbalance — anomalies are rare, so accuracy is misleading; use precision/recall on the rare class.
  • Threshold — the single most important knob; set by acceptable false-alarm rate.
  • UAV uses — engine/telemetry health, intrusion detection, crop-disease or infrastructure-defect spotting.
Exam line — Anomaly detection is one-class: you model normality and flag deviations, because anomalies are too rare and varied to learn directly. Tune the threshold below to trade recall against false alarms.

WP 04
Level · the map

Self-Organizing Maps

A self-organizing map (Kohonen map) is an unsupervised neural network that projects high-dimensional data onto a low-dimensional (usually 2-D) grid while preserving topology — points close in the data end up close on the map. It's clustering and visualisation at once.

Competitive learning. Each grid node holds a weight vector in the data space. For a sample, the closest node is the best-matching unit; it and its grid neighbours move toward the sample. Learning rate and neighbourhood radius shrink over time, so the sheet first unfolds coarsely, then fine-tunes.
Topology preservation

Because neighbours are updated together, adjacent map nodes stay adjacent in data space. The trained grid becomes a readable 2-D chart of a complex distribution — regions of the map correspond to types of input.

SOM vs K-means

K-means gives K independent centroids. A SOM's nodes are linked in a lattice and organise into a map, giving neighbourhood structure and a visualisation K-means can't.

UAV use — organise unlabelled image or spectral features into a map for exploration, or cluster telemetry regimes. Train the lattice below and watch it unfold onto the data.

WP 05
Formation · many drones

Single- & Multi-UAV Systems

A single UAV senses and acts alone. A multi-UAV system (a swarm) coordinates many, often with no central controller: each drone follows local rules and useful global behaviour — coverage, formation, search — emerges. Coordination can be learned (multi-agent RL) or hand-designed (flocking).

Emergent flocking (Boids)

Three local rules — cohesion, alignment, separation — produce coordinated flocks from purely local sensing. Scalable and robust: no leader to lose, degrades gracefully if a drone drops out.

Centralised vs decentralised

Centralised control is optimal but a single point of failure and hard to scale. Decentralised swarms scale and survive failures, at the cost of global optimality. Comms range and bandwidth shape what's possible.

  • Coverage — spread out to observe an area fastest; more UAVs cover more, if separation is respected.
  • Formation / consensus — agree on headings or shapes from local exchanges.
  • Trade-offs — communication, collision risk and coordination cost rise with fleet size.
Exam line — Swarm behaviour is emergent from simple local rules; it needs no leader and scales gracefully. Set the fleet to 1 vs many below and compare the coverage.

WP 06
Cruise · learning from reward

Reinforcement Learning & Q-learning

Reinforcement learning is learning to act. An agent in an environment observes a state, takes an action, and receives a reward; it learns a policy that maximises long-term reward. No labelled examples — only the consequences of its own choices, delayed and sparse.

The MDP. States, actions, a transition model, a reward, and a discount γ that values sooner reward over later. The goal is a policy π(a|s) maximising expected discounted return. Q-learning learns the value Q(s,a) of taking action a in state s, updating toward reward + γ·(best next value) — and acts greedily on it.
Exploration vs exploitation

Always taking the current-best action never discovers better ones. ε-greedy acts randomly a fraction ε of the time. Explore too little and it gets stuck; too much and it never commits. ε usually decays over training.

On the grid

Tabular Q-learning stores a value per state–action. It's exact and simple but the table explodes with state size — fine for a small grid, hopeless for raw pixels. That limit is what Deep Q-Networks remove.

UAV use — vision-based navigation as an MDP: state = what the drone sees, actions = moves, reward = progress to goal minus collisions. Train the gridworld below and watch the policy converge.

WP 07
Climb · scaling up

Deep Q-Networks

A Deep Q-Network replaces the Q-table with a neural network Q(s,a;θ) that takes raw state — even pixels — and outputs a value per action. This lets RL generalise across unseen states and scale to high-dimensional vision, but training a network on its own moving targets is unstable, so DQN adds two stabilisers.

Experience replay

Store transitions in a buffer and train on random minibatches from it. This breaks the correlation between consecutive samples and reuses data, turning RL into something closer to stable supervised learning.

Target network

The bootstrap target uses a separate, slowly-updated copy of the network. Without it the target shifts every step as θ changes — the network chases itself and diverges. Freezing the target periodically stabilises training.

  • Function approximation — one network generalises to states never seen, unlike a table.
  • Loss — regress Q(s,a) toward r + γ·maxₐ′Qtarget(s′,a′).
  • Extensions — Double DQN, Dueling DQN, prioritised replay improve stability and value estimates.
Exam line — DQN = Q-learning + a neural network, made stable by experience replay and a target network. Toggle each off below and watch the reward curve destabilise.

WP 08
Cruise · policy methods

Proximal Policy Optimization

Value methods like DQN learn Q and act greedily. Policy-gradient methods instead learn the policy π(a|s) directly, adjusting action probabilities in the direction of higher reward — natural for continuous or stochastic control. PPO is the popular, robust member of this family.

The clip. Plain policy gradients can take a step so large it wrecks the policy. PPO limits each update by clipping the probability ratio between new and old policy to a small band (1±ε), so the policy improves in reliable, bounded steps — stable and simple to tune.
Advantage

Each action is pushed by its advantage — how much better than average it did. Better-than-expected actions get more probable; worse ones, less. The clip caps how much per update.

Why PPO is popular

It's an on-policy method that is stable, sample-efficient enough, and needs little tuning. It handles continuous actions (velocities, headings) that DQN's discrete argmax can't, making it a default for UAV control.

Exam line — PPO improves the policy while clipping the update size, trading a little speed for a lot of stability. Small clip = slow and smooth; large clip = fast but it can overshoot. See it below.

WP 09
Approach · coordinate & stay safe

Multi-Agent, Hierarchical RL & Collision-free Operation

Real UAV autonomy stacks these ideas. Multi-agent RL has several learning drones sharing an environment; hierarchical RL splits control into levels; and every policy must ultimately fly collision-free — toward its goal without hitting obstacles, or each other.

Multi-agent RL

Each drone's environment now contains other learners, so it is non-stationary: everyone's policy shifts at once. Approaches range from independent learners to centralised-training / decentralised-execution, where a shared critic coordinates during training only.

Hierarchical RL

A high-level policy picks sub-goals ("go to waypoint", "search sector"); low-level policies execute them ("adjust velocity"). Decomposing the task shortens the reward horizon and makes long missions learnable.

  • Collision-free operation — reward progress, penalise proximity; or wrap a learned policy in a reactive safety layer (potential fields, reciprocal velocity obstacles).
  • Vision-based navigation — the state is what the camera sees; the policy maps pixels to velocities, avoiding obstacles it perceives.
  • Safety vs performance — a bigger safety margin means fewer near-misses but longer, slower paths.
Exam line — Multi-agent RL is hard because the environment is non-stationary; hierarchical RL tames long horizons by decomposing goals; collision-free flight combines a goal-seeking policy with obstacle and inter-agent avoidance. Fly the fleet below.

Revision & Quiz

Quick self-check tap to reveal
How does unsupervised learning differ from supervised learning?
Supervised learning maps inputs to known labels; unsupervised learning finds structure (groups, outliers, layout) in unlabelled data, judged by internal measures rather than accuracy.
What does K-means minimise, and why does it converge?
The within-cluster sum of squares. Each assign–update step can only lower it, so it converges — to a local optimum that depends on the initial centroids.
Why is accuracy a poor metric for anomaly detection?
Anomalies are rare, so a model that flags nothing scores high accuracy. Use precision/recall on the rare class, and tune the threshold for an acceptable false-alarm rate.
What makes a SOM different from K-means?
A SOM's nodes are linked in a lattice and update their neighbours together, so it preserves topology and yields a 2-D map. K-means gives K independent centroids with no neighbourhood structure.
State the exploration–exploitation trade-off.
Exploiting the current-best action maximises immediate reward but may miss better options; exploring tries alternatives. ε-greedy balances them, usually decaying ε over training.
What two mechanisms stabilise a DQN, and why?
Experience replay breaks correlations between consecutive samples and reuses data; a target network keeps the bootstrap target fixed for a while so the network doesn't chase its own moving target.
What is the role of the clip in PPO?
It caps how far the policy can move in one update (ratio within 1±ε), preventing destructive large steps — trading some speed for much greater stability.
Why is multi-agent RL harder than single-agent?
Other agents are also learning, so each agent's environment is non-stationary — the transition/reward dynamics shift as everyone's policy changes at once.

Key Takeaways

If you remember only one thing

Two label-free ways to learn: unsupervised methods discover structure in data (group it, flag the odd one out, map it), and reinforcement learning turns reward into action — from a Q-table on a grid, to deep and policy-gradient methods, to swarms that fly collision-free. Neither needs the bounding boxes of Units III–IV.

Unsupervised = structure, no labels

Clustering, anomaly detection and SOMs turn unlabelled aerial data into groups, alerts and maps, judged by internal measures not accuracy.

02

K-means minimises within-cluster spread

Assign to nearest centroid, move centroid to the mean, repeat. Simple and fast; you choose K, and init matters.

03

Anomaly detection models normality

Learn what's normal, score the distance, threshold it. Rare-class metrics and the threshold–false-alarm trade-off are everything.

04

Agent–environment–reward; Q-learning values state–actions and acts greedily. ε-greedy balances exploration and exploitation.

07

DQN scales RL to pixels

A network replaces the Q-table; experience replay and a target network make training stable enough to work.

08

Policy-gradient with a clipped update: bounded, stable steps toward higher reward; handles continuous control DQN can't.

09

Many learners make the world non-stationary; hierarchy tames long horizons; safe flight fuses goal-seeking with avoidance.
